Tryton Equivalent Name module
#############################

Register equivalent values for diferents models name field values.

It is useful in cases where the names of external sources are different from those registered in the models, allowing them to be easily searched.

One practical use is when it is used as a resource for AI models directly or through an MCP server. For example, in a purchase where product names do not match those registered in Tryton or where queries may have ambiguous results.


Installing
----------

Drop the content of this folder on trytond/modules and update database.
